# ProxyEnv Switch

A small Windows 11 utility for adding, updating, or removing the current user's `HTTP_PROXY` and `HTTPS_PROXY` environment variables.

![ProxyEnv Switch icon](assets/proxyenv-switch.png)

## What it does

Enter a local proxy port such as `60505`, then choose an action:

- **Add / Update Proxy** sets:

  ```text
  HTTP_PROXY=http://127.0.0.1:60505
  HTTPS_PROXY=http://127.0.0.1:60505
  ```

- **Remove Proxy** deletes both variables.

The utility changes only:

```text
HKEY_CURRENT_USER\Environment
```

Administrator rights are not required. It does not change machine-wide environment variables.

## Download and run

Download the executable for your Windows computer from the repository's **Releases** page:

- `ProxyEnvSwitch_x64.exe` for most Intel and AMD Windows 11 computers
- `ProxyEnvSwitch_ARM64.exe` for Windows 11 ARM computers
- `ProxyEnvSwitch.exe` for the Python/PyInstaller build generated by GitHub Actions

After changing the variables, reopen terminals and applications that were already running. Existing processes keep the environment values they inherited when they started.

## Improved interface

Version 1.1 includes:

- A DPI-aware, resizable window
- Wrapped subtitle and status text, preventing clipping at higher Windows display scaling
- Full-width action buttons
- A display of the current persistent `HTTP_PROXY` and `HTTPS_PROXY` values
- Port validation from `1` to `65535`
- No network access, telemetry, or background service

## Build the Python EXE

Requirements:

- Windows 11
- Python 3.10 or later
- Internet access when installing PyInstaller

Run:

```bat
scripts\build-python-exe.bat
```

The result is created at:

```text
dist\ProxyEnvSwitch.exe
```

Manual equivalent:

```powershell
py -m pip install -r requirements-dev.txt
py -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name ProxyEnvSwitch `
  --icon assets\proxyenv-switch.ico `
  src\proxyenv_switch.pyw
```

## Build the dependency-free native EXEs

Requirements:

- Go 1.23 or later

From PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-native-exes.ps1
```

This creates:

```text
dist\ProxyEnvSwitch_x64.exe
dist\ProxyEnvSwitch_ARM64.exe
```

The native build is included so users can run the utility immediately without installing Python. The Python/Tkinter source remains the main readable reference implementation.

## GitHub Actions

The included workflows automatically:

- Build native x64 and ARM64 Windows EXEs
- Build the Python/PyInstaller Windows EXE
- Upload build artifacts
- Create release assets when a version tag such as `v1.1.0` is pushed

Example release command:

```powershell
git tag v1.1.0
git push origin v1.1.0
```

## Security and privacy

ProxyEnv Switch:

- Writes or removes only `HTTP_PROXY` and `HTTPS_PROXY` under the current user
- Does not require administrator rights
- Does not connect to the Internet
- Does not transmit or collect data
- Does not run in the background

Review [`SECURITY.md`](SECURITY.md) for reporting security issues.
